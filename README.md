# hha-calculator

A single-page app that calculates your Happy Home Academy (HHA) score in
*Animal Crossing: New Horizons*, room by room. It covers base points, furniture count,
series, sets, concepts, categories, color matching, feng shui, lucky and seasonal items,
and penalties, and shows a line-item breakdown of where every point came from.

Status: planning. The design lives in `DESIGN.md`. Licensed MIT (see `LICENSE`).

Not affiliated with Nintendo. Item data comes from the community ACNH data spreadsheet.
